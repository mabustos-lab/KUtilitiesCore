# KUtilitiesCore
KUtilitiesCore es una colección completa de utilidades y Frameworks .NET reutilizables, diseñados para acelerar el desarrollo de aplicaciones en los ámbitos de MVVM, acceso a datos, registro y seguridad. Este repositorio ofrece un ecosistema modular de bibliotecas que se pueden utilizar de forma independiente o conjunta para crear aplicaciones .NET sólidas sobre **.NET 10**; las bibliotecas de abstracciones (`KUtilitiesCore.DataAccess`) y logging (`KUtilitiesCore.Logger`) se conservan además en `netstandard2.1` y `netstandard2.0` respectivamente, por lo que siguen siendo consumibles desde runtimes .NET anteriores. Nota: el uso de DPAPI (`ProtectedData`, `KUtilitiesCore.Encryption`) requiere Windows.
El repositorio contiene seis bibliotecas básicas y sus correspondientes proyectos de prueba, cada uno de los cuales aborda problemas de desarrollo específicos. Para obtener información detallada sobre los componentes individuales, consulte Core Utilities, MVVM Framework, Data Access Layer, Logging System, Security and Encryption y Application Updates.
